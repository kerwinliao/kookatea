# KooK@Tea

Hugo site using the [Blowfish](https://github.com/nunocoracao/blowfish) theme, deployed to GitHub Pages by `.github/workflows/hugo.yml`.

- Homepage text: `content/_index.md`
- Name, headline, avatar, social links: `config/_default/languages.en.toml`
- Theme options: `config/_default/params.toml`
- Colours: `assets/css/schemes/kooktea.css`
- Animated background: `assets/img/background.svg`

The theme is downloaded during each deployment (pinned version in the workflow), so it is not stored in this repository.
